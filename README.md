# BEMARA

Toda tú. Con claridad.

BEMARA es una plataforma consumer premium para mujeres, orquestada por LENA. Este repositorio inicia la Fase 0 definida por los manifiestos oficiales dentro de `IDENTIDAD `.

## Estado

- Monorepo pnpm + Turborepo.
- Apps separadas: web/PWA, mobile, operations, API y workers.
- Paquetes compartidos: design tokens, dominio, i18n, validation, config, safety, SDK, UI web y UI mobile.
- Migración SQL inicial con RLS para privacidad, Life Graph, memoria, LENA, notificaciones y entitlements.

## Fuente de verdad

- `IDENTIDAD /BEMARA_Manifiesto_Maestro_Codex_v1.md`
- `IDENTIDAD /BEMARA_Manifiesto_Maestro_Producto_Desarrollo_v1.docx`
- Assets oficiales de marca, color, tipografía y UI dentro de `IDENTIDAD `.

## Regla de producto

BEMARA no debe reinterpretarse como CRM, ERP, dashboard administrativo, app médica, marketplace clínico ni chatbot genérico. LENA es la única inteligencia visible para la usuaria.
